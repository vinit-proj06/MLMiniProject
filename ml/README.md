# How the machine learning works

Run training from the project root, after installing the root `requirements.txt`:

```powershell
python -m ml.train
```

The saved artifacts are generated locally and excluded from Git. Run training once after cloning. Starting the API or making a prediction then loads them and **does not train the models again**. Run this command again only when intentionally rebuilding the models.

## Files

- `features.py`: the 20 feature names in a fixed order and source label mappings.
- `dataset.py`: reads the original Kaggle CSV, removes unit suffixes, maps categories, and checks the schema.
- `download_data.py`: optional repeatable download from the official Kaggle API.
- `train.py`: creates the holdout split, fits both pipelines, measures their performance, and saves artifacts.

The dataset and labeling limitations are described in [the data README](../data/README.md).

## Preprocessing without leakage

1. Apply known, deterministic column and category mappings. For example, `842 mAh` becomes `842` and `Yes` becomes `1`. This step does not learn anything from other rows.
2. Split the 2,000 rows into 1,600 training rows and 400 test rows using `train_test_split(test_size=0.20, random_state=42, stratify=target)`. Each training class has 400 rows and each test class has 100 rows.
3. Fit preprocessing inside each Scikit-learn `Pipeline`, using **only the training rows**. A median `SimpleImputer` makes the saved pipelines robust to missing values, although this source file has none. The public prediction form still requires every field.
4. The SVM pipeline also fits `StandardScaler` on the training data. Scaling prevents large-valued features such as RAM from dominating merely because their units have a larger numerical range. Random Forest splits by feature thresholds, so it does not need scaling.
5. Evaluate the trained pipelines once on the untouched test set. Both models use the same split. Do not choose model settings by repeatedly looking at the test result.

The models are deliberately straightforward:

| Model | Fixed settings | Reason |
| --- | --- | --- |
| Random Forest | 300 trees, seed 42, default remaining tree settings | Combines many decision trees and handles nonlinear feature interactions. |
| SVM | Linear kernel, C=1.0, seed 42 | A simple scaled multiclass SVM baseline with no test-set tuning. |

SVM probability calibration is disabled. The project predicts a class and does not present a made-up confidence score. Model selection is the user's choice, and the comparison shows both measured results.

## Evaluation and artifacts

`models/metrics.json` is generated by training, never filled in manually. It contains accuracy and **macro-averaged** precision, recall, and F1; a confusion matrix; and a classification report for each model. Macro averaging calculates a score for each class and gives the four classes equal weight. In each confusion matrix, rows are actual labels and columns are predicted labels, ordered Low, Medium, High, Very High.

Additional metadata records source URL, original CSV checksum, row counts, feature order, class distributions, training date, package versions, and model settings. `models/split.json` records the original row indices assigned to train and test so the calculation is reproducible.

`models/random_forest.joblib` and `models/svm.joblib` contain the fitted pipelines, including preprocessing. Pass a pandas DataFrame with columns ordered as `FEATURE_NAMES` to `pipeline.predict`. The target column is never part of the input features. The artifacts use standard Scikit-learn classes and need no custom prediction-time transformer.

Joblib model files should only be loaded from trusted sources. Use the package versions in the project's `requirements.txt` to generate and load the artifacts consistently. After changing dependency versions, regenerate and verify the artifacts with `python -m ml.train`.

This is one held-out evaluation, not a guarantee about unseen modern devices. Because all labels come from this dataset, the project predicts relative price ranges, not currency amounts.
